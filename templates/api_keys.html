🔌 API & Dokumentation

Nutze die eBay Agent Cockpit API für programmatischen Zugriff auf deine Daten.

API Keys

🔐 Authentifizierung

Alle API-Requests müssen mit einem API Key authentifiziert werden. Verwende den Header Authorization mit dem Format: Bearer KEY:SECRET

curl -H "Authorization: Bearer YOUR_KEY:YOUR_SECRET" \ https://ebay-agent-cockpit.onrender.com/api/watchlist

📊 Rate Limiting

Jeder API Key hat ein Rate Limit. Standard ist 1000 Requests pro Stunde.

Response Headers
X-RateLimit-Limit: 1000 X-RateLimit-Remaining: 995 X-RateLimit-Reset: 1234567890

🚨 Fehlerbehandlung

Die API gibt standardisierte Fehler zurück:

{ "success": false, "error": "Invalid API key or secret" }
